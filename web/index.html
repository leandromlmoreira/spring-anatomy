Rode na sua máquina

A interface funciona sozinha no navegador. A API é um Spring Boot 3 com Java 21, H2 em memória e Swagger: classes de produção e classes de teste.

API Spring

./mvnw spring-boot:run
./mvnw test

Swagger em localhost:8080/swagger-ui.html. Sem rede, use --anatomy.endereco.estrategia=offline.

Interface

cd web
npm install
npm run dev

Vite em localhost:5173. npm test roda o Vitest e npm run test:e2e o Playwright.
